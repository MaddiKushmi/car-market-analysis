# Car Market Analysis

## Project Description

This project analyzes Car Dekho used-car data using Python and
data visualization techniques.

## Objective

The objective is to identify important factors affecting used-car
selling prices and understand market trends.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The dataset contains information about:
- Car Name
- Manufacturing Year
- Selling Price
- Present Price
- Kilometres Driven
- Fuel Type
- Seller Type
- Transmission
- Previous Owners

## Data Analysis

The project includes:

- Dataset exploration
- Missing value checking
- Duplicate detection and removal
- Descriptive statistics
- Fuel type analysis
- Transmission analysis
- Price relationship analysis
- Correlation analysis
- Data visualization

## Key Findings

- No missing values were found in the dataset.
- Two duplicate records were identified and removed.
- Present Price has a strong positive relationship with Selling Price.
- Petrol cars are the most represented fuel type.
- Diesel cars have the highest average selling price among the fuel types in the dataset.

## Tools

Python, Pandas, NumPy, Matplotlib and Seaborn.
